# 原始升级方案执行状态

基准文件：`available-computing-升级改造方案.md`。本文件只记录与原方案验收项直接相关的进度。

## 阶段一：数据模型与新鲜度

- 已完成 Model 验证时间、验证方式、免费类型、过期时间和新鲜度展示。
- 已完成 Channel 凭证状态、配置类型、发现来源和合规审核快照。
- 已完成现有 Channel 合规记录回填；未找到明确条款的厂商显式标为 `unknown`，不留空。
- Alembic 升级与回滚已验证。

## 阶段二：声明式厂商与候选池

- 声明式适配器当前覆盖 Mistral 与 Kilo Gateway；Kilo 免费模型支持匿名调用，无需 Key/信用卡。真实频道发现 346 个模型、识别 10 个免费模型，并已通过统一 `/v1/chat/completions` 代理完成端到端调用。
- Google Gemini 与 NVIDIA NIM 因不满足用户收紧后的准入策略而撤回。
- 候选池定时抓取两份社区清单，只写入待审核表，不自动注册厂商或创建 Channel。
- 已实现解析数量校验、连续两次失败告警状态、失败保留旧数据、JSON/Markdown diff 报告和 YAML 草稿。
- 后台新增“候选厂商”页，可查看草稿、标记已审核或忽略。
- 已完成首轮 11 个候选的官网审核并将证据写回候选池：9 个因固定额度、credits、限时免费或支付方式要求被排除，Mistral Codestral 合并为已有厂商，Kilo 通过准入。
- 当前注册表支持 7 家厂商；后续扩容继续排除信用卡、一次性赠金、固定日/月额度和限时试用型服务。

## 阶段三：三层探测

- 已完成入库基线、动态预算心跳、事件复检批次和 30 分钟三次失败阈值。
- 个人版执行边界明确不实现多节点探测；保持单机密钥存储。

## 阶段四：Key 策略与 API

- 已完成 Key 级厂商策略、RPM/RPD、上下文和偏好。
- 已完成请求级排除、偏好和 fallback chain，以及诊断响应头。
- 已完成 chat、embedding、rerank、image 路由，并用 `personal-main` 经统一代理完成真实验收：Kilo Chat 返回 200，硅基流动 Embedding 返回 1024 维向量、Rerank 返回有效排序结果，智谱 Image 返回有效图片 URL。
- 代理转发鉴权已委托给 Adapter：匿名频道不会发送空 Bearer Header，且匿名模型的 401/403 不会把 Channel 误标成 Key 失效。

## 阶段六：通知与管理体验

- 已完成站内消息中心、未读红点、四类去重通知和 Dashboard 方案要求的四项汇总指标。
- Channel 状态、候选池异常和事件复检会通过 WebSocket 推送刷新；服务重启后由状态对账补齐漏报。
- 已预留通用通知 Sink/Dispatcher 抽象，后续可按需挂接 Webhook、邮件或企业微信。
